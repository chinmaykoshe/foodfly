# FoodFly 🍕🚀

A modern, full-stack food delivery application built with React and Node.js that allows users to browse restaurants, view menus, place orders, and track deliveries in real-time.

## Overview

FoodFly is a complete food delivery platform with role-based access control, allowing customers to order food and admins to manage the platform. The application features a responsive user interface built with React and a robust backend powered by Node.js and Express with serverless functions.

## Tech Stack

**Frontend:**
- React.js (96.7% of codebase)
- React Router DOM (for navigation and routing)
- HTML5 (1.3%)
- CSS3 (2.0%)

**Backend:**
- Node.js
- Express.js
- Serverless Functions

**Deployment:**
- Vercel (Frontend)
- Serverless backend with CORS support

## Features

- 🏠 **Home Page** - Landing page with featured restaurants and promotions
- 🍽️ **Menu Browsing** - View restaurant menus with detailed food items
- 📋 **Shopping Cart** - Add items to cart, manage quantities, view totals
- 🛒 **Order Management** - View, track, and manage your orders
- 💳 **Checkout** - Secure checkout process with order confirmation
- 👤 **User Profile** - Manage user profile and order history
- 🔐 **Authentication** - Secure login and signup with role-based access
- 📱 **Responsive Design** - Optimized for mobile, tablet, and desktop
- 👨‍💼 **Admin Panel** - Admin dashboard for managing orders and restaurants
- 📍 **Real-time Order Tracking** - Track order status in real-time
- ℹ️ **About Us** - Learn more about the FoodFly platform
